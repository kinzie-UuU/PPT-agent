# PPT Agent 产品目标与后续计划

## 目标

把 `E:\PPT工具` 做成一个围绕两套 Skill 的本地 PPT Agent，而不是普通 PPT 模板工具。

主流程固定为：

```text
上传源 PPT / PDF / 图片 / brief
-> codex-ppt 生成视觉统一的图片型 PPT
-> image-to-editable-ppt / editppt 重建对象级可编辑 PPT
-> 质量检查、人工复核、失败恢复、交付门禁
-> 下载最终 editable-final.pptx
```

两套 Skill 的边界：

- `codex-ppt`：负责重画视觉统一的图片型页面和图片型 PPT 中间产物。
- `image-to-editable-ppt`：负责把图片型 PPT、PDF 或页面图片重建成对象级可编辑 PPT。

旧模板、旧本地生成器、旧设计方向最多只保留在高级诊断或兼容区，不能作为主流程，也不能冒充产品级结果。

## 核心限制

1. 图片模型和对话模型必须分开判断。
   `gpt-image-2` 正常只能说明图片生成可用；页面理解、结构化 JSON 和可编辑重建仍依赖对话模型或页面规格模型。

2. OCR 只是辅助。
   OCR 用来提供文字提示和校对线索，不能替代 `image-to-editable-ppt` 的视觉理解和对象重建。

3. 图片型 PPT 只是中间产物。
   最终交付必须是对象级可编辑 PPT，不能只给图片型 PPT 或整页截图 PPT。

4. 外部 API 调用必须显式确认。
   `gpt-image-2`、图片编辑、页面规格模型等真实调用会消耗额度，不能自动静默执行。

5. 交付门禁不能绕过。
   PPT 打不开、证据过期、整页截图冒充、页面证据缺失、人工复核未记录时，不能开放最终交付。

6. 旧模板不能回到主线。
   旧模板效果不稳定，且和双 Skill 目标不一致。需要继续隐藏或移除旧入口。

## 当前问题

### P0：最终交付还差人工视觉复核

2 页 `editable-final.pptx` 已生成，且可打开、可编辑，但系统不能自动判断“视觉是否足够接近目标图”。当前需要人工确认：

- 页面主体信息没有丢失
- 标题、Logo、主要视觉结构保留
- 可编辑预览和目标图大体一致
- 没有明显错位、遮挡、空白或错误元素

完成复核后，交付门禁才能从 blocked 进入可交付或草稿可交付状态。

### P0：完整 15 页产品验收未完成

已有 15 页工程验证报告，但其中 `codex-ppt` 全量视觉页是 passthrough/dry-run 证据，不是产品级真实图片生成。因此它只能证明工程链路，不证明最终产品效果。

### P1：前端仍偏工程控制台

普通用户应该只看到：

```text
上传文件 -> 生成视觉统一 PPT -> 转成可编辑 PPT -> 检查 -> 下载
```

现在仍有 worker、manifest、hash、provider、gate、artifact 等工程信息露出太多。后续要默认折叠到“高级详情”。

### P1：文档和历史状态存在乱码

部分 README、验收报告、历史 job state 中有 mojibake。它们不一定影响运行，但会影响判断、交接和维护。

### P1：失败恢复仍需产品化

现在已经有失败页重试、fresh run recovery、worker task 等能力，但用户视角还不够清楚。应该把“失败原因 -> 推荐动作 -> 一键恢复”做成稳定前端流程。

## 产品级完成标准

### 1. 1 页真实闭环

- `gpt-image-2` 生成真实图片型页面
- `image-to-editable-ppt` 生成页面级可编辑 PPT
- 页面包含可编辑文本、形状、图片对象
- 页面不是整页截图
- PowerPoint 能打开
- 页面预览和目标图大体一致

### 2. 2 页小样本闭环

- `page_001,page_002` 均完成可编辑重建
- 两页都能通过页面证据检查
- 自动合成 `editable-final.pptx`
- 最终文件 PowerPoint 可打开
- 交付门禁只剩人工复核，或人工复核后可下载

### 3. 前端可理解

打开 `http://127.0.0.1:4180/` 后，用户能直接知道：

- 当前工具做到哪一步
- 当前卡在哪里
- 为什么不能下载
- 下一步应该点哪个按钮
- 最终文件在哪里

工程细节默认进入高级详情。

### 4. 15 页真实验收

- 用真实 15 页 PPT 完整跑完双 Skill 主线
- 全量 `codex-ppt` 视觉页不能是 passthrough/dry-run
- 全量 `image-to-editable-ppt` 可编辑重建成功
- 最终 PPT 页数正确、能打开、可编辑
- 无整页截图冒充
- 交付门禁通过
- `workspace/v1-acceptance/latest-real-ppt-regression.json` 中 `acceptance.ready=true`
