# PPT Design Tool Checklist

## P0 必须通过

- 每页必须有 `layout`，并且来自 `design-system/layouts.json`。
- 每页 bullet 不超过对应 layout 的 `maxBullets`。
- 标题必须短，中文建议不超过 24 字；太长先改写，不靠缩小字号硬塞。
- 首页必须是 `cover`，最后一页优先用 `closing` 或 `quote`。
- 5 页以上至少出现 3 种 layout；8 页以上至少出现 5 种 layout。
- 不能连续 3 页使用同一种正文结构。
- 保存文字后必须重新生成 PPTX 和预览图，预览图片 URL 必须带新的 `?v=` 版本号。
- PNG 预览失败时必须保留可读的兜底预览，不能让中间画布空白。
- PPTX 是主交付物；PDF 或 PNG 失败不能阻塞 PPTX 下载。

## P1 质量建议

- 先讲场景或机会，再讲卖点和证据，最后给推荐动作。
- 数据页必须有真实数字；没有数字时不要使用 `kpi`。
- 对比页的 bullet 数量尽量成对，避免左右失衡。
- 销售战卡要保留价格逻辑、推荐话术、适用对象和下一步动作。
- 产品图、包装图、价格带和适用对象要参与大纲规划，不后贴。
- 不确定的信息进入 `risk-checklist`，不要伪造成确定结论。

## P2 视觉约束

- 图片、图表、卡片都应留出页脚安全区。
- 一页只强调一个主信息，不把所有卖点塞进同一页。
- 主题色来自 `themes.json`，不要临时拼新颜色。
- 同组多图保持相同比例、边距和视觉重心。
