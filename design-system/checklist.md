# PPT Design Tool Checklist

## P0 必须通过

- 每页必须有 `layout`，并且来自 `design-system/layouts.json`。
- 每页 bullet 不超过对应 layout 的 `maxBullets`。
- 标题必须短，中文建议不超过 24 字；太长先改写，不靠缩小字号硬塞。
- 首页必须是 `cover`，最后一页优先用 `closing` 或 `quote`。
- 不能整套 PPT 只有一种正文结构，5 页以上至少出现 3 种 layout。

## P1 质量建议

- 先讲场景/机会，再讲卖点/证据，最后给推荐动作。
- 数据页必须有真实数字；没有数字时不要用 `kpi`。
- 对比页的 bullet 数量应尽量成对，避免左右失衡。
- 销售战卡要保留价格逻辑、推荐话术、适用对象、下一步动作。

## P2 视觉约束

- 图片、图表、卡片都应留出页脚安全区。
- 一页只强调一个主信息，不把所有卖点塞进同一页。
- 主题色来自 `themes.json`，不要临时拼新颜色。
