# PPT 美学设计系统与智能生成 Agent

## 最终目标

打造一套 PPT 美学设计系统和智能生成 Agent，同时支持：

1. 已有 PPT 优化重塑。
2. 从零开始生成 PPT，即使输入只有一句话、一张图或一份零散资料。

系统需要理解用户资料、原稿文字、原图、产品信息、价格信息，以及用户提供的可选参考图和风格约束。它先判断任务类型与资料强度，再生成可确认的大纲和风格样张。用户确认风格后，系统再输出完整、可编辑、可导出的 PPTX，并自动完成审美、结构、图片、文字密度、事实一致性和交付质量检查。

最终形态不是简单 PPT 生成器，而是一个能保留原始事实和素材、理解审美风格、主动检查问题、可从一句话或一张图起稿，也可把旧 PPT 重塑成专业商业提案的 PPT 设计 Agent。

## 两个核心入口

### 旧 PPT 优化重塑

输入：

- 旧 PPT。
- 原图、原文和页面结构。
- 用户补充说明。
- 内置或自定义风格库。

目标：

- 保留事实、原始素材和案例逻辑。
- 重塑叙事结构、页面节奏、版式层级和审美风格。
- 输出可编辑 PPTX，并提供 PDF/PNG 预览导出。

标准流程：

```text
上传旧稿
→ 原稿识别报告
→ 智能路由和可编辑大纲
→ 风格样张
→ 多 Agent 自动质检
→ 用户确认
→ 全套重塑
→ 多 Agent 自动质检
→ 导出
```

### 从零开始生成 PPT

输入：

- 一句话需求。
- 一张图。
- PDF、PPT、Excel、Word 或多张素材图。
- 产品、价格、受众、场景等补充信息。

目标：

- 判断资料强度。
- 标记系统推断和待确认项。
- 生成可编辑初稿，而不是假装资料完整。

标准流程：

```text
输入需求或上传资料
→ 资料强度判断
→ 智能路由和大纲
→ 风格样张
→ 多 Agent 自动质检
→ 用户确认
→ 全套生成
→ 多 Agent 自动质检
→ 导出
```

## 系统分层

### 资料理解层

职责：

- 提取 PPTX、PDF、DOCX、XLSX 和图片资料。
- 识别原 PPT 每页文字、图片、来源页码和素材关系。
- 抽取产品、价格、规格、风险、客户对象和待确认字段。

验收：

- 旧 PPT 上传后能看到逐页识别报告。
- 每张抽取图片能追溯到原 PPT 页码。
- 每页能显示原文摘要、图片数量和绑定状态。

### 智能路由层

职责：

- 判断任务类型：销售战卡、客户提案、产品介绍、数据汇报、旧稿优化、轻量资料整理等。
- 决定页数、章节、layout 队列、图片页、价格页、风险页。
- 为 AI 内容生成提供明确约束。

验收：

- 路由结果可见。
- AI 不能临时决定整套结构。
- 实际生成结果可计算 route adherence。

### 风格系统层

职责：

- 管理内置风格和自定义风格库。
- 上传风格参考图。
- 将风格图片内化成结构化风格指纹。
- 本地先生成确定性风格指纹，后续再接云端视觉模型补强。

风格指纹应包含：

- 主色和辅助色。
- 留白程度。
- 图片裁切方式。
- 字体气质。
- 画面密度。
- 卡片、边框、分割线习惯。
- 适合场景。
- 禁用风格。

验收：

- 每个风格库都有结构化风格说明。
- 每张参考图都有可见的本地风格指纹，例如色彩倾向、亮度、饱和度、画面密度和构图比例。
- 同一内容切换不同风格时视觉差异明显。
- 生成时能证明使用了对应风格库，而不是混用所有图片。

### 样张确认层

职责：

- 全套生成前先输出 3-4 页最终样式。
- 样张覆盖封面、视觉页、信息页和收尾页。
- 用户确认后才允许生成完整 PPT。

验收：

- 未确认样张时，完整生成按钮不可用。
- 样张有 PPTX 和 PNG 预览。
- 样张记录使用的风格、路由、参考图数量和质量警告。

### Agent 复审层

职责：

- 大脑 Agent 负责判断当前阶段、下一道门禁和是否需要人工确认。
- 路由 Agent 负责检查任务类型、页数、layout 队列和 route adherence。
- 素材 Agent 负责检查原文、原图、页码绑定和生成页 `imageSlots`。
- 风格 Agent 负责检查风格库、样稿覆盖和视觉调性约束。
- 交付 Agent 负责检查 PPTX、预览图、导出和可继续编辑状态。
- 本地规则检查结构、页数、layout、图片槽、导出状态。
- 云端模型检查审美、语义、图片匹配、事实一致性和文字密度。
- 样张生成后先多 Agent 复审，再交给用户确认。
- 完整 PPT 输出后再多 Agent 复审一轮，再进入编辑和导出。
- 云端视觉复审为 `warn/block` 时，先自动修复一轮，再重新生成预览并复审。

验收：

- 样张必须经过多 Agent 自动质检。
- 配置 API Key 时，样张应进入云端视觉复审。
- 复审结果可见，并能转成自动修复建议。
- 自动修复最多一轮，仍未通过时应明确阻断并提示需要更深层补图或重绘。

### 生成执行层

职责：

- 按确认大纲和确认风格生成完整 deck。
- 生成可编辑 PPTX，而不是静态截图。
- 支持导出 PDF 和 PNG。

验收：

- PPTX 文件存在且可下载。
- PNG 预览数量等于页数。
- 导出失败不能阻塞 PPTX 主交付。

### 缺图策略层

职责：

- 优先使用原 PPT 图片和用户上传图片。
- 风格库图片只作为风格参考，不直接挪用为内容图。
- 仅在缺封面主视觉、缺产品图、缺场景图或缺背景纹理时建议远端补图。
- 远端补图前必须让用户确认。

验收：

- 系统能区分原图、用户素材、风格参考图和 AI 补图。
- AI 补图被明确标记，不能混同为原始素材。

## 当前实现状态

已具备：

- PPTX 文本抽取。
- PPTX 内嵌图片抽取，并记录 `sourceSlide`。
- 智能路由 `routeDeck()`。
- 本地 fallback 和云端 AI 生成。
- 本地校验 `validateDeck()`。
- 样张确认接口 `/api/jobs/style-preview`。
- 原稿识别报告 `sourceReport`，可显示旧 PPT 每页文字量、图片数、绑定页码和识别风险。
- 多 Agent 复审结果 `agentReviews`，覆盖大脑、路由、素材、风格和交付分支。
- 云端视觉复审 `cloudReviews`，会读取样稿/整稿预览图并作为云端视觉 Agent 进入质检门禁。
- 云端视觉复审后的样稿自动修复记录 `visualFixes`。
- 生成页图片槽匹配报告 `imageSlotReport`，可看到按原稿页码命中的页数。
- 风格参考图本地风格指纹 `styleFingerprint`，并汇总进路由与风格 Agent 复审。
- 视觉复审不通过后的补图/复用原图计划 `imageSupplementPlan`，会区分原稿图、上传素材、风格参考图和远端补图，并把“原图优先、远端补图需确认、不得虚构事实”写入交付状态。
- 内置风格和自定义风格库。
- 风格参考图分组、移动和上传。
- PPTX/PDF/PNG 导出。

明显缺口：

- 风格库图片已有本地确定性风格指纹，但还没有云端视觉模型增强分析。
- 样张生成后已有多 Agent 复审和云端视觉复审；云端可阻断不合格样稿。
- 样张云端复审 `warn/block` 后已能自动修复一轮并二次复审。
- 完整 PPT 已接入云端视觉复审入口，但还需要更多回归样例验证稳定性。
- 当前自动修复仍偏规则级，遇到“图片像占位、风格不够强”时可能仍然 block，需要接缺图/补图和更深的版式重绘。
- 原 PPT 图片已能绑定到原始页码，并能校正生成页 `imageSlots`；后续还需提升图片语义选择质量。
- 缺图策略已有只读计划和 UI 展示，但还没有“一键复用原图重绘 / 用户确认后远端补图”的执行按钮。

## 近期优先级

1. 按 `imageSupplementPlan` 执行一键复用原图重绘，并再次跑 PNG + 云端视觉复审。
2. 用户确认后接入远端补图，并标记 AI 补图来源。
3. 根据云端视觉复审结果做更深的版式重绘。
4. 风格指纹与版式/token 的更细粒度映射。
5. 完整 PPT 云端复审回归测试与旧稿优化回归测试集。
